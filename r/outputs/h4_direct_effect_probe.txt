Rows      2688
Baseline  a = 2.8207   b = 0.4120   c = 0.7716   c' = -0.3906

c' is the effect of oddity on discomfort with unexpectedness held
constant. It is negative and the total effect is positive, so the two
pathways run in opposite directions. Everything below asks whether that
negative sign is a finding or an artifact.

====================================================================================
5. SENSITIVITY - how much confounding would erase c'?
====================================================================================

c' conditions on the mediator, which is measured after treatment. If any
unmeasured variable causes both unexpectedness and discomfort, the two
equations have correlated errors and both b and c' are biased.

Let rho = Corr(error in the M model, error in the Y model). Under the
linear model the bias-corrected paths are

    b(rho)  = b_hat  - k(rho)
    c'(rho) = c'_hat + a * k(rho)      where k(rho) = rho/sqrt(1-rho^2) * s2/s1

with s1, s2 the residual SDs of the two models. rho = 0 recovers the
reported estimates. This is the Imai-Keele-Yamamoto correlated-error
idea; medsens() automates a refined version of it.

====================================================================================
6. PROPENSITY - a weak, falsifiable probe of the curiosity story
====================================================================================

The curiosity reading makes a directional prediction. If oddity without
unexpectedness reads as interesting rather than threatening, then people
who describe themselves as adventurous should show a STRONGER (more
negative) direct effect than cautious ones.

This is not a test of curiosity. Propensity is a self-reported travel
disposition, not a curiosity measure, and a null result is equally
consistent with the curiosity story being right and propensity being
the wrong proxy. It is included because the prediction is falsifiable
in one direction: a REVERSED result would count against the reading.

  Predicted:  c'(Adventurous) more negative than c'(Cautious)
  Observed:   Adventurous = -0.3312   vs   Cautious = -0.4095
  The difference is not significant, so propensity provides NO support
  for the curiosity reading. It does not refute it either - propensity
  is a poor proxy, and this test had no power to speak of.
  Note the point estimates also run the WRONG way, which is mildly
  discouraging for the reading even though it is not significant.

  Whatever happens to c', note whether the b path is moderated: that is
  a separate and better-powered finding about who converts unexpectedness
  into discomfort, and it does not depend on the curiosity story at all.

====================================================================================
8. WHAT THIS DOES AND DOES NOT ESTABLISH
====================================================================================

Established, if the sections above came back clean:
  - c' is estimated from real overlapping data, not extrapolated.
  - The negative sign reappears within unexpectedness strata, with no
    mediation model and no linearity assumption.
  - It is not an artifact of treating an ordinal mediator as continuous.

NOT established:
  - Curiosity. There is no curiosity measure in this dataset. Several
    other mechanisms predict the same negative sign: the odd element
    making an otherwise ambiguous scene legible, a contrast effect
    against the unexpectedness rating just given, or scale anchoring.
  - Causality. c' conditions on a post-treatment variable, so it is only
    causal under an assumption section 5 shows to be fragile.

Suggested wording for the thesis:
  Report the negative direct effect as a robust empirical pattern.
  Offer curiosity as an interpretation, explicitly flagged as untested,
  and cite the sensitivity tipping point so the reader can see how much
  unmeasured confounding the claim tolerates. Do not use partial or full
  mediation language, and do not compute a proportion mediated.
